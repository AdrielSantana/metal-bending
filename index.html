BEND IN THE BROWSER

Bend programs running on every core of your machine, inside a web page. No GPU, no JavaScript backend: the same C runtime a native binary uses, compiled to WebAssembly.

Each demo below is a .bend file built with bend file.bend -o file.html from bendlang/bend#866: Emscripten compiles Bend's C runtime with -pthread -mtail-call, so the fork-join scheduler runs on a Web Worker per core and the segment machine's tail calls become wasm tail calls. A Window draws on a canvas, paced by the display; the line under it counts the frames the Bend program delivered. Add ?threads=1 to any demo to see what the cores buy.

Demos

Mandelbrot — 512×512, the whole quadtree recomputed every frame with parallel calls. 60 fps on 10 cores, ~29 fps on one. Bendcraft — first-person voxel world you can edit. WASD move · arrows look · I/K up/down · J break · L place · Esc quits. 60 fps. Voxel raycaster — 512×512 rays, DDA through a voxel grid, orbiting camera. 24 fps on 10 cores; the GPU version does 60 on Metal. Ray tracer — the upstream demo as is: 1024×768, ray-marched spheres on a checkered plane, hard shadows, its own fps in the corner. W/A/S/D fly · Q/E up/down · arrows turn/look · Esc quits. 19 fps on 10 cores, 4 on one; the Metal build does 60. Ray tracer, 512×384 — the same program with the camera scaled to a quarter of the pixels (source). 60 fps on 10 cores, 14 on one. Pong — the upstream demo. W/S and Up/Down move the paddles, Esc quits. 60 fps. Triangle — the upstream demo the web playground runs on one core. 60 fps.

Needs a browser with SharedArrayBuffer and wasm tail calls: Chrome 112+, Firefox 121+, Safari 18.2+. Measured on Chrome 153 on an Apple M5 (10 cores). GitHub Pages sends no COOP/COEP headers, so a small service worker (coi-serviceworker) adds them and reloads the page once on your first visit.

Numbers

A windowless 512×512 Mandelbrot, 50 iterations, summed to a checksum; time around the computation only, median of five frames. Same checksum in every cell.

So the browser runs at ~1.2x the native binary and scales with the cores the same way: 20x over the JavaScript target on one core, ~100x on ten. What stays on the desktop is Metal: on the Mac's demos the GPU adds another 2–4x over ten cores, and the pull request explains why WebGPU cannot take that role today.

Source
